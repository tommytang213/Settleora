# Current Android image-to-preview qualification candidate

Source-only candidate, no executable admission. This is a minimal supervisor of
current repository product code and its unchanged Android Flutter test command.
It imports no Northstar61-file overlay, changes no parser/preview/model/fixture
truth, and does not transfer any consumed native or cleanup packet authority.

## Scope and bindings

Current all101 immutable image-to-preview integration tests and their existing
additional native controls run unchanged. No single-case flag or weaker score is
introduced. Native results and strict fixture quality remain distinct from setup,
process exit and cleanup. nativeReady is always false here: independent acceptance
collection and exact-head tests/reviews/CI remain separate downstream gates.

A new packet binds current clean Git head, a frozen tracked-source tar archive,
all six tool executables, the actual Android system image hash, exact model/fixture
input bytes, this supervisor, existing disposable_lifecycle.py, unchanged
bounded-process-capture.mjs, independent exact five-file capsule/review receipts,
protected source/history pins, five qualification locks and one managed execution
job. Atlas independently authenticates actual model/tool launch history and admits
the exact packet; ordinary executor approval remains mandatory. An audit reference,
file hash, JSON boolean or invocation object is not platform permission.

No current checkout, old overlay, consumed directory or saved diagnostic is edited
or deleted by the runner. The source archive is extracted into a fresh private
scratch tree, refusing symlinks, special files, traversal and duplicate members.
Model/fixture copies are hash-checked. Pub resolution is offline and may not change
the pinned lockfile. Builds write generated files only in that isolated source.
Normal pinned Flutter startup necessarily writes cache engine stamps/realm/lock;
Flutter Gradle plugin build state and offline Pub cache may also be written.
These exact scopes are declared by the packet and checked, never hidden behind an
SDK-copy/alternate mount/read-only claim. The warm tool snapshot/key must remain
present; tool rebuild/upgrade/download is not admitted. Any actual platform denial
is terminal, never bypassed via another SDK, credentials, access or mount.

## Bounds, retained evidence and failure

Fixed phases: preparation300s, emulator boot600s, current full native test10800s
(existing CI180minute bound), cleanup90s. Each direct owned cleanup wait<=20s,
constrained by remaining cleanup allowance. Observations, log-size checks and
maintenance/Boston/known-work gates run during the native wait. Uninterruptible
kernel/filesystem calls and scheduler delay cannot be made atomically bounded;
no later effect is authorized after the next deadline check. Zero native retries.
ADB/emulator/command logs above4MiB fail into cleanup; original scratch is retained.

Cleanup is always attempted on failure. If own processes or related sessions remain,
a new native candidate appears, active qualification sockets remain (kernel-only
TIME_WAIT without an inode is excluded), or evidence/release fails, report failure
and retain the unresolved managed epoch for coordination. Never claim clean because
an intermediate wrapper disappeared. No-child precheck failure performs no cleanup
effects. A previously existing run is never recaptured or modified.

The existing lifecycle captures bounded diagnostic prefixes and completeness flags,
then a single-use terminal record with actual test status, cleanup proof and false
native readiness. All private per-command logs stay in scratch even when only
allowlisted summaries/prefixes are retained. Never delete source/logs or pretend
truncation is complete evidence. Failed test exit propagates as a nonzero normal
executor status; normal executor return and actual postflight/registry settlement
must be independently read back before declaring this epoch complete.

are intentionally distinct from the supported server listen form. This does not
claim an observed binary run before admission.
