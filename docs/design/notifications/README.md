# Notification Design References

This folder records notification UX/reference packets for future Settleora UI
implementation tasks. These documents describe product-facing readout states,
copy, layout, privacy, and accessibility guidance only.

They do not authorize runtime APIs, OpenAPI changes, generated-client edits,
schema or migration work, admin web implementation, mobile or user web
implementation, provider sending, provider credentials, device-token handling,
deployment changes, Figma API output, or secrets.
