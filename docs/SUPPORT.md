# Support

Thank you for your interest in Settleora.

## Questions and general discussion

Please use GitHub Discussions for:

- Questions
- Ideas
- General feedback
- Usage discussion
- Roadmap suggestions

## Bugs and scoped work

Please use GitHub Issues only for:

- Confirmed bugs
- Clearly scoped technical problems
- Reproducible errors
- Maintainer-approved work items

## Sponsorships

Settleora can be supported through GitHub Sponsors.

Sponsorships are voluntary donations only. They do not provide paid support, priority handling, commercial rights, ownership, or guaranteed feature work.

## Commercial use

This project is not licensed for commercial use unless separately agreed in writing by the maintainer.
