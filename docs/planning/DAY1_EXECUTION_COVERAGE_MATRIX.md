- GitHub Project: `Settleora Day 1 Execution Board`

- Interpretation: the 64 seeded issues are an execution-board skeleton, not complete Day 1 coverage.

Coverage status meanings:

- `covered`: existing issue coverage is specific enough for the current planning level.
- `partially covered`: an epic or broad issue exists, but more future feature/task/sub-task issues are still needed.
- `missing`: no sufficiently specific existing seeded issue was found.
- `needs decision`: source requirements conflict, are ambiguous, or need product/architecture gating before ticket generation.
- `deferred day2/day3`: explicitly outside Day 1 or intentionally represented as Day 2/Day 3.
