# Day 1 Manual Gate Package

This checklist is for a future maintainer-run Day 1 acceptance gate. It does not record any manual review as passed.

| Gate section | Pass criteria | Evidence to attach or record | Blockers if failed | Owner / reviewer | Status placeholder |
| --- | --- | --- | --- | --- | --- |

## Stop Conditions

Stop the Day 1 acceptance gate if any review requires:

- Changing Day 1 scope or moving Day 1 requirements to a later day without explicit maintainer decision.
- Runtime/API/auth/session/security/schema/generated-client/deployment/storage/privacy/money behavior changes inside the evidence task.
- Marking manual UI retest, manual code review, security review, deployment review, or production readiness as passed without actual evidence.
- Accepting unresolved money, storage/privacy, auth/session, settlement, or deployment risks.
