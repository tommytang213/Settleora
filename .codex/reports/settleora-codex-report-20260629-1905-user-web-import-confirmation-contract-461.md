## Backend Handlers, Domain, Persistence, Tests

- Added `BillCsvImportSession`, scope constants, and status constants.
- Added additive EF table `bill_csv_import_sessions`.
- Session rows bind to auth account, auth session, actor profile, scope, optional group, status, expiry, payload digest, preflight result version, and confirmation challenge.
- Session creation reuses the existing CSV parser/planner/calculation path and stores safe review metadata plus normalized candidate JSON. It does not create bills or final import audit.
- Confirmation revalidates current actor/session ownership, scope, group ID, digest, preflight version, challenge, session lifecycle, profile access, and group membership before creating draft bills and final import audit.
- Discard makes pending sessions non-confirmable.
- Focused tests added for personal session confirmation, digest/challenge mismatch, group membership revalidation, discard, expiry, and model entity count.
